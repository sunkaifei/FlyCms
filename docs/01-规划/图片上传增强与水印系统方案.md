# 图片上传增强与水印系统方案（R 批次：对标全 CMS 图片上传设置）

> ✅ **状态（2026-10-02）：R 批次全量落地验收**——probe_watermark 11/11（文字水印右下/图片水印+随机位置/GIF 跳过/小图跳过/关闭语义/设置白名单保存回显）。
> 上传响应已带 watermarked 标记与原图尺寸；水印图路径限站内 /upload/**。
>
> 版本：v1.0（2026-10-02）
> 目标：图片上传能力对齐主流 CMS——**水印（文字/图片、九宫格位置/随机、透明度/边距）、
> 压缩质量控制、多尺寸联动**；全部后台「网站设置」配置，零代码切换。

## 1. 全 CMS 图片上传/水印设置对标

| 系统 | 水印能力 | 位置/方式 | 其他上传设置 |
|---|---|---|---|
| **帝国 CMS** | 文字/图片水印；GIF 不加（保动画） | 九宫格位置（左上/中/右下…）+ 随机位置；透明度、边距可调 | 缩略图宽度、远程附件保存 |
| **DedeCMS** | 图片/文字水印 | 九宫格 + 随机；透明度、JPEG 干扰线 | 大图限制尺寸、缩略图宽高 |
| **PHPCMS** | 文字/图片水印 | 九宫格；透明度 | 水印透明度、缩略图质量 |
| **WordPress** | 核心无水印（插件二方） | 插件定（九宫格/平铺/随机，多水印源） | big image 阈值（2560px 自动降档）、多尺寸档位 |
| **Typecho / Z-Blog** | 插件实现 | 同上 | 基础 |
| **Halo** | 核心无，插件 | 插件定 | 存储策略（本地/S3/OSS）多策略 |
| **极致/迅睿** | 文字/图片 | 九宫格+随机，透明度/边距/角度 | 缩略图规格多档、压缩质量 |

**对标共识**：水印 = **来源（文字/图片）× 位置（九宫格/随机）× 样式（透明度/字号或缩放/边距）**；
且都对 GIF 动图跳过水印。FlyCms 现状 = 全无。本方案按共识实现，规格命名向帝国/迅睿看齐（国内用户直觉）。

## 2. 设计（R 批次）

### 2.1 站点设置（网站设置页新增「图片上传与水印」分组，全部白名单键）

| 键 | 含义 | 取值 | 默认 |
|---|---|---|---|
| `fly_wm_enabled` | 水印总开关 | 1/0 | 0 |
| `fly_wm_type` | 水印类型 | text（文字）/ image（图片） | text |
| `fly_wm_text` | 水印文字 | ≤30 字 | 空 |
| `fly_wm_font_size` | 文字字号 | 12–72 | 16 |
| `fly_wm_font_color` | 文字颜色 | #RRGGBB | #FFFFFF |
| `fly_wm_image` | 水印图片 URL（type=image 用） | 站内 /upload/** 路径 | 空 |
| `fly_wm_position` | 位置 | 1–9 九宫格（1 左上…5 居中…9 右下）+ 10=随机 | 9（右下） |
| `fly_wm_opacity` | 透明度 | 10–100（%）；文字为 alpha、图片为合成 alpha | 60 |
| `fly_wm_margin` | 边距(px) | 0–100（距边留白） | 10 |
| `fly_wm_min_width` | 加水印最小图宽 | 0–4000（小图加水印会糊，默认 300 以下跳过） | 300 |
| `fly_wm_quality` | JPG 压缩质量 | 50–100 | 85 |

### 2.2 水印引擎（core/utils/ImageWatermarkUtil，纯 Java2D 无新依赖）

- **入口**：`watermark(File img, WatermarkConfig cfg)`——读图 → 按类型叠加 → 按原格式写回（png 保透明/gif 跳过保动画/jpg 用 quality）；
- **位置计算**：九宫格按 (图宽-元素宽-2×边距) 三等分取点；position=10 随机 → 在九宫格内随机取一格（每次上传随机，非每像素随机）；
- **文字**：`Graphics2D` + 默认字体（SansSerif 派生，中文可渲染）按 fontSize 画字符串，alpha=opacity/100；
- **图片水印**：读取水印图（站内路径，用户在附件库/上传选一张）→ 按原图宽度 1/6 等比缩放 → alpha 合成 drawImage；
- **触发点**：管理端直传（/api/system/images/upload）落盘后、多尺寸生成前——**只给原图加水印**（缩放副本从已水印原图派生，天然带水印）；
- **跳过条件**：GIF（保动画）/ 原图宽 < min_width / 水印类型=image 但图片 URL 无效；
- **安全**：水印图路径限站内 /upload/**（防任意文件读）；字号/透明度/边距全部数值白名单。

### 2.3 管理端设置 UI

「网站管理」设置页新增「图片上传与水印」分组（10 个键，与既有 SMTP/AI 分组同渲染方式）；
水印图片选择复用附件库选图交互（填 /upload/ 路径）。

### 2.4 上传响应增强

`POST /api/system/images/upload` 返回体补：`{width, height, watermarked(bool), sizes(JSON 原样透传)}`——前端控件/附件库可展示"已加水印"标记与原图尺寸。

## 4. 验收标准

① 开文字水印（右下/透明 60/字号 16）→ 直传图右下角出现文字，原图被覆写，多尺寸副本带水印；② 图片水印（选附件库图）→ 右下角出现缩放后的水印图；③ 位置=10 随机 → 连传 3 张位置不全相同；④ GIF 上传不加水印（动画保留）；⑤ 小于最小宽的图跳过；⑥ 域名/相对路径不受影响；⑦ 网站设置分组保存回显正常。
