# FlyCms 广告系统手册

> 2026-09-30 落地。对标帝国/Dede/PHPCMS 的广告模块（广告位 + 广告 两层结构），
> 目标：管理员建位、投广告后，主题模板一行标签即可上线广告。

## 1. 结构与概念

```
广告位 fly_ad_position          广告 fly_ad
├─ 名称（首页轮播）             ├─ 所属广告位（position_id）
├─ 调用标识 ad_key（唯一）  ←──→ ├─ 类型：image 图片 / text 文字 / code 代码
├─ 建议尺寸（宽×高）            ├─ 素材：imageUrl / textContent / htmlCode（按类型三选一）
├─ 排序 / 状态                  ├─ 跳转链接（点击经 /ad/click/{id} 计数后 302）
└─ 停用=整位不输出              ├─ 权重（越大越靠前）+ 排序
                                ├─ 投放时间窗（start/end，空=立即/永久）
                                ├─ 状态（停用=不输出）
                                └─ 展示计数 count_view / 点击计数 count_click
                                   + fly_ad_stat_daily 按 (广告,日期) 落明细
```

**统计口径**：每次「展现」（fly_ad 标签渲染 / JS 分发被页面加载）计 1 次展示；
每次「点击」（/ad/click/{id} 被访问）计 1 次点击。双写两处：
`fly_ad.count_view/count_click`（累计总数，列表快显）+ `fly_ad_stat_daily`（按日明细，
UNIQUE(ad_id, stat_date) upsert 累加，支撑点击率与按天报表）。报表端点返回的
statDate 已格式化为 `yyyy-MM-dd` 字符串（避免时区漂移）。

**管理端**：广告列表新增「点击率」列（CTR=点击/展现）；每条广告操作里有**「统计」**
弹窗——合计数 + 近 7/30 天按日明细（日期/展现/点击/点击率），权限节点 900368
（/api/system/ad/stat/list）。

设计约定：
- 图片地址**直存 URL**（E3 image_url 语义，不挂 fly_images 引用计数），前台渲染零联表；
- `ad_key` 创建后不可改（模板按 key 调用，改键=模板悬空），格式 `^[a-z][a-z0-9_]{0,63}$`；
- 广告所属位不可改（换位=删除重建，统计口径不混乱）；
- 删除位前必须清空位下广告（防误删整组投放）。

## 2. 前台调用（主题模板）

一行直出（快速上线）：

```html
<@fly_ad key="home_carousel"/>
```

图片广告输出 `<a href="/ad/click/{id}" target="_blank"><img .../></a>`，
文字广告输出 `<a>文字</a>`，代码广告原样输出（联盟代码直接贴）。

**JS 调用代码（联盟式，同百度联盟/谷歌联盟取码模式）**：

后台「广告管理 → 广告位行操作 → 代码」一键生成并复制：

```html
<script src="http://你的域名/ad/js/home_carousel"></script>
```

- 粘贴到任意模板页面**甚至站外页面**即可上线广告（document.write 直出，同标签缺省输出）；
- 端点 `/ad/js/{adKey}` 公开、`application/javascript;charset=UTF-8`、`Cache-Control: no-cache`
  （后台改广告即时生效），渲染计展示、点击走 /ad/click 计数；
- 管理端弹窗里域名默认取当前访问地址，跨站投放时改成正式站点域名；
- 与上面的 FreeMarker 标签二选一：JS 适合快速上线/跨站，标签适合主题内 SEO 友好直出。

自定义循环（需要套轮播组件等场景）：

```html
<@fly_ad key="home_carousel" rows="5">
  <div class="carousel">
    <#list adList as ad>
      <a href="/ad/click/${ad.id}" target="_blank"><img src="${ad.imageUrl}"/></a>
    </#list>
  </div>
</@fly_ad>
```

body 内变量：
- `adList`：id / name / adType / imageUrl / url / textContent / htmlCode / countView / countClick
- `adPosition`：id / name / adKey / width / height

规则：仅输出「启用 + 时间窗内」的广告，按 `weight desc, sort, id desc` 排序；
渲染即计展示（一条批量 SQL）；广告位停用则整位输出空。

## 3. 后台功能（vben：系统管理 → 广告管理）

- 广告位列表：名称/标识/尺寸/广告数/排序/状态，操作=广告管理、**代码（获取 JS/标签调用码）**、编辑、删除；
- 广告管理（位下）：新增/编辑/删除广告；类型切换联动素材表单；
  图片支持「从附件库选择」（存 URL 快照）；时间窗 DatePicker（yyyy-MM-dd HH:mm:ss）；
- 展示/点击计数实时可见（展示=前台渲染次数，点击=/ad/click 次数）。

## 4. 接口（/api/system/ad/**，权限节点 900360~900367）

| 端点 | 说明 |
|---|---|
| GET  /position/list | 广告位分页（keyword 模糊，含 adCount 联查） |
| POST /position/save \| update \| delete | 位 CRUD（update 不可改 adKey；delete 校验位下无广告） |
| GET  /ad/list?positionId= | 位下广告分页 |
| GET  /ad/js/{adKey}（公开） | 联盟式 JS 分发：document.write 缺省 HTML，no-cache |
| GET  /ad/click/{id}（公开） | 点击计数 +1 后 302 跳转广告链接 |
| GET  /stat/list?adId=&positionId=&days= | 按日统计（节点 900368），行 statDate/views/clicks |
| POST /ad/save \| update \| delete | 广告 CRUD（save 带 positionId；update 不可改位；素材按类型必填校验） |

时间参数格式 `yyyy-MM-dd HH:mm:ss`（@DateTimeFormat）。
