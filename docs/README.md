# FlyCms 文档中心

> 最后更新：2026-09-28

本目录按**文档生命周期**分为四类。新成员建议按「01-规划 → 02-手册 → 03-报告」的顺序阅读：
先知道**要做什么**，再知道**怎么做**，最后看**之前做过什么**。

## 目录说明

| 目录 | 放什么 | 生命周期 |
|---|---|---|
| `01-规划/` | 要做的、正在做的事：总体规划、专项开发方案、执行清单 | 长期，随进展更新 |
| `02-手册/` | 怎么做：可执行的开发指南、接入规范 | 长期，稳定少变 |
| `03-报告/` | 做过什么：一次性审查报告、补齐报告（按日期倒序） | 一次性，只归档不改 |
| `04-运维/` | 部署与运维配置 | 运维物 |
| `assets/` | 文档配图、截图 | 素材 |

**模块维度不丢**：见下方索引表的「涉及模块」列。加新文档不用挪目录，打标签即可。

## 约定

- **一次性产出必须带 `YYYY-MM-DD-` 日期前缀**，方便按时间排序；长期文档不带。
- **报告只归档不改**。报告里指出的问题若已修复，在索引表状态列标注，不回头改报告正文。
- **状态用三态**：`未做` / `骨架就绪待接 UI` / `已实测验证`。禁止只写"已完成"——见 2026-09-28 那份审查报告的教训。
- 文档中引用 SQL 迁移脚本时，一律指向仓库内 `sql/` 下的**全量快照**（历史 `stage-*.sql` 已清理，引用会失效）。
